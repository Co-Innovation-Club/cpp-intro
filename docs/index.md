<h2 class="cover-section-title" id="about">写在前面</h2>

::: tip 关于本文档
本文档面向C++初学者，以小熊猫C++为配套环境，讲解语言核心语法；所讲语法全平台通用。

选用小熊猫C++的原因有二：算法竞赛普遍采用此类开发环境；Visual Studio 2026默认以UTF-8保存源文件，中文输出易乱码，需另行设置。
:::

::: warning 装过其他版本Dev-C++？
如果此前安装过Orwell Dev-C++或其他分支版本，建议先清理旧的配置再安装，否则可能沿用旧设置导致编译异常。
:::
