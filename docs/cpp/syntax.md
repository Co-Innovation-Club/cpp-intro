# 基本语法

## 语句

C++ 代码由一行行**语句（statement）**组成。语句就是程序执行的一条操作命令。规则很简单：**每条语句以分号结尾**，除非有明确规定可以不写。

```cpp
int x = 1;
```

上面这条语句声明了整数变量 `x`，并把它的值设为 `1`。

多条语句可以挤在一行：

```cpp
int x; x = 1;
```

换行不是语法要求，只是方便人看。反过来，一条语句也能拆成好几行，编译器靠分号判断语句在哪儿结束：

```cpp
int x;
x
=
1
;
```

第二个语句 `x = 1;` 被拆成了四行，编译器会自动忽略中间的回车。

单独一个分号也是合法语句，叫**空语句**，什么也不做：

```cpp
;
```

## 表达式

C++ 的各种计算靠**表达式（expression）**完成。表达式是一个"求值式"，算完会得到一个结果。

```cpp
1 + 2
```

上面就是一个表达式，它的结果是 `3`。

表达式加上分号就成了语句，但通常没有意义：

```cpp
8;
3 + 4;
```

表达式和语句的区别主要有两点：

- 语句里可以包含表达式，但表达式本身不是语句；
- 表达式总有值，语句不一定。比如声明语句 `int x = 1;` 只是执行了一个动作，并不产生一个"结果值"。

## 语句块

一对大括号 `{}` 可以把若干语句包成一组，称为**语句块**，也叫复合语句。

```cpp
{
    int x;
    x = 1;
}
```

大括号本身不写分号。语句块在后面讲作用域、流程控制时会反复用到。

## 空格

空格的作用是分隔语法单位。能不能不加，取决于不加会不会引起歧义。

```cpp
int x = 1;
// 等同于
int x=1;
```

赋值号 `=` 前后有没有空格都行，因为编译器靠 `=` 本身就能分清左右两边。

多个连续空格等价于一个：

```cpp
int    x =     1;
```

空格还用来做缩进。缩进对编译器毫无影响——完全不缩进的代码照样能跑——它的价值全在"给人看"。约定俗成，下一层代码比上一层多缩进一级。本书统一缩进 **4 个空格**。

```cpp
if (x > 0) {
    cout << "positive\n";
}
```

只含空格的行叫**空白行**，编译器直接忽略。

## 注释

注释是写给人的说明，编译器会跳过它。C++ 有两种注释。

第一种是用 `/* ... */` 包起来，可以跨行：

```cpp
/* 注释 */

/*
  跨行注释
*/
```

它也能插在行内，用来标注参数：

```cpp
int open(char* s /* file name */, int mode);
```

这种注释必须记得写结束符 `*/`，漏掉会让注释一直吞到下一个 `*/`，很容易埋坑：

```cpp
cout << "a "; /* 注释一
cout << "b ";
cout << "c "; /* 注释二 */
cout << "d ";
```

上面本来想注释掉第一行和第三行的行尾，结果第一行漏了 `*/`，注释一一路延续到第三行结束，第二行整行都被吃掉了。

第二种是 `//`，从它到行尾都算注释，只能单行。可以放行首，也可以跟在语句后面——这是日常最常用的一种。

```cpp
// 整行注释

int x = 1; // 行尾注释
```

两种注释都不能写进字符串。双引号里的 `//` 和 `/* */` 只是普通字符，不具备注释功能：

```cpp
cout << "// hello /* world */ ";
```

另外，预处理阶段注释会被替换成一个空格，所以 `min/* space */Value` 会变成 `min Value`，而不是 `minValue`。

## 输出：cout

本书大量用到输出。C++ 首选的方式是 `cout`，它来自标准库的 `<iostream>`（被 `bits/stdc++.h` 一并包含）。

### 基本用法

`cout` 是"字符输出流"（character output），配合左移运算符 `<<` 把数据送到屏幕：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, world!\n";
    return 0;
}
```

`<<` 在这里念作"插入"，意思是把右边的数据插进输出流。它的好处是**类型自动识别**——不用告诉 `cout` 你要输出的是整数还是小数，它自己看着办：

```cpp
int a = 3;
double b = 1.5;
cout << a << ' ' << b << '\n';   // 输出：3 1.5
```

一行里可以串很多个 `<<`，依次输出。

有两个细节竞赛里要记住：

- `cout` **不会**自动分隔或换行，`3` 和 `1.5` 之间的空格、结尾的换行，都得自己写。
- 换行用 `'\n'`（字符），别用 `endl`。两者的区别是 `endl` 还会强制刷新缓冲区，慢；`'\n'` 不刷新，快。竞赛里输出量大时，这个差别能决定会不会超时。

```cpp
cout << "a\n";       // 推荐：只换行
cout << "a" << endl; // 不推荐：换行 + 刷新缓冲
```

### 与 printf 的分工

`cout` 写起来省事，但**格式化**能力弱：想固定保留两位小数、想按十六进制输出，用 `cout` 就要额外摆弄一堆操纵符，反而不如 C 的 `printf` 干脆。所以竞赛里的常规做法是：

- 日常输出用 `cout`；
- 需要精确控制格式（小数位数、宽度、补零、进制）时用 `printf`。

`printf` 的用法见下一节。

## 格式化输出：printf

### 基本用法

`printf`（print formatted，格式化打印）来自 `<cstdio>`，跟 C 里的 `printf` 是一回事。

```cpp
printf("Hello World");
```

它也不自动换行。要换行，在文本末尾加 `\n`：

```cpp
printf("Hello World\n");
printf("Hello\nWorld\n");
```

### 占位符

`printf` 的文本里可以放**占位符**，运行时用后面的参数填进去：

```cpp
// 输出 There are 3 apples
printf("There are %i apples\n", 3);
```

`%i` 就是一个占位符：`%` 是标志，`i` 表示这里要填一个整数。`printf` 的第二个参数 `3` 就填进这个位置。常用的除了 `%i`（等价于 `%d`），还有 `%s`：

```cpp
printf("%s will come tonight\n", "Jane");
```

一行里可以放多个占位符，按位置一一对应：

```cpp
printf("%s says it is %i o'clock\n", "Ben", 21);
// 输出 Ben says it is 21 o'clock
```

占位符和参数是严格对应的：有 `n` 个占位符，就要给 `n` 个对应参数。**数量对不上是竞赛里常见的低级错误**，输出会变成内存里的乱值，还不一定报错。

下表按字母顺序列出常用占位符，供查阅：

- `%a`：十六进制浮点数，字母小写。
- `%A`：十六进制浮点数，字母大写。
- `%c`：单个字符。
- `%d`：十进制整数。
- `%e`：科学计数法的浮点数，指数部分 `e` 小写。
- `%E`：同上，指数部分 `E` 大写。
- `%i`：整数，基本等同于 `%d`。
- `%f`：小数（`float` 和 `double` 都用它）。
- `%g`：6 位有效数字的浮点数，超过就转科学计数法。
- `%G`：同 `%g`，指数部分大写。
- `%hd`：`short`。
- `%ho`：八进制 `short`。
- `%hx`：十六进制 `short`。
- `%hu`：无符号 `short`。
- `%ld`：十进制 `long`。
- `%lo`：八进制 `long`。
- `%lx`：十六进制 `long`。
- `%lu`：无符号 `long`。
- `%lld`：十进制 `long long`。
- `%llo`：八进制 `long long`。
- `%llx`：十六进制 `long long`。
- `%llu`：无符号 `long long`。
- `%Le`：科学计数法的 `long double`。
- `%Lf`：`long double`。
- `%n`：把已输出的字符数写进参数指向的变量，本身不输出。
- `%o`：八进制整数。
- `%p`：指针地址。
- `%s`：字符串。
- `%u`：无符号整数。
- `%x`：十六进制整数。
- `%zd`：`size_t` 类型。
- `%%`：输出一个百分号 `%`。

### 输出格式

`printf` 还能控制输出的格式。

**（1）限定宽度。** 在 `%` 和类型符之间写一个数字，表示最小宽度，不够就补空格：

```cpp
printf("%5d\n", 123);   // "  123"
printf("%-5d\n", 123);  // "123  "，加 `-` 改为左对齐
```

默认右对齐。对小数，这个宽度限制的是**整个数字**占的最小位数：

```cpp
printf("%12f\n", 123.45);  // "  123.450000"
```

**（2）强制显示正负号。** `%` 后面加 `+`，正数也会带上 `+`：

```cpp
printf("%+d\n", 12);   // +12
printf("%+d\n", -12);  // -12
```

**（3）限定小数位数。** 用 `%.nf` 保留 `n` 位小数：

```cpp
printf("Number is %.2f\n", 0.5);  // Number is 0.50
```

这是竞赛里最常用的一条——**浮点数答案几乎都要 `%.2f`、`%.6f` 这样定精度**。它还能和宽度一起写：

```cpp
printf("%6.2f\n", 0.5);  // "  0.50"
```

宽度和小数位数都可以用 `*` 占位，由参数传入：

```cpp
printf("%*.*f\n", 6, 2, 0.5);
// 等同于
printf("%6.2f\n", 0.5);
```

**（4）只输出字符串的前几位。** `%.[m]s` 取前 `m` 个字符：

```cpp
printf("%.5s\n", "hello world");  // hello
```

## 标准库与头文件

程序需要的功能不一定都要自己写。C++ 自带一套**标准库（standard library）**，里面的功能都被写进了标准，用法固定，所以可移植、可靠。

标准库按功能拆到不同的**头文件（header file）**里。要用某个功能，就得先把它所在的头文件包含进来，用的是 `#include` 指令。比如 `cout` 在 `<iostream>` 里：

```cpp
#include <iostream>
```

不过如《C++ 简介》所说，竞赛里更省事的写法是开头只写一句 `#include <bits/stdc++.h>`，把标准库一次全引来：

```cpp
#include <bits/stdc++.h>
using namespace std;
```

关于头文件、`#include` 以及 `bits/stdc++.h` 到底是什么，见《预处理器》一章。

需要注意的是，C++ 里表示 C 标准库头文件时，习惯写成 `<cstdio>`、`<cstring>` 这种形式（把 `.h` 换成前缀 `c`），表示"这是 C 的头文件，但内容被放进了 `std` 命名空间"。它们和 C 里的 `<stdio.h>`、`<string.h>` 一一对应，功能相同。
