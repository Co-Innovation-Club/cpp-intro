# 字符编码

## Unicode 简介

早期字符编码主要面向英语文本，使用 7 位 ASCII 码表示字符。ASCII 的范围是 0 到 127，可以覆盖英文字母、数字和常用符号，一个字节（8 位）可以完整存储这些编码。这也是 `char` 类型占 1 个字节的历史原因。

ASCII 无法表示其他语言的字符。中文包含数万个常用字，一个字节无法覆盖，需要使用多个字节表示一个字符。早期各国分别制定编码，同一串字节使用不同编码解释时会得到不同内容，影响数据交换。Unicode 为每个字符分配一个唯一编号，以统一字符表示。

这个编号称为**码点**（code point），写作 `U+` 加十六进制。例如，`U+0041` 表示字母 `A`。码点范围从 `U+0000` 到 `U+10FFFF`，可以容纳一百多万个字符；其中 0 到 127 的范围与 ASCII 完全重合，用于保持向前兼容。

码点只表示编号，存储时使用的具体字节由**编码方式**（encoding）决定。Unicode 标准委员会规定了三种编码方式：

| 编码 | 表示一个码点用几个字节 | 特点 |
| --- | --- | --- |
| UTF-8 | 1 到 4 个 | 变长；ASCII 字符仍占 1 字节，与 ASCII 完全兼容 |
| UTF-16 | 基本平面 2 个，其余 4 个 | 以定长为主；Windows 内部和 Java 的 `char` 用它 |
| UTF-32 | 固定 4 个 | 定长，处理方式固定，占用空间最多 |

**UTF-8 是目前广泛使用的编码方式**，Linux、macOS、网页和大多数源码文件都使用它。UTF-8 采用变长编码并兼容 ASCII：英文字符仍占 1 个字节，纯英文文件使用 UTF-8 或 ASCII 存储时内容相同；汉字等字符通常占 3 个字节。

ASCII 字符占 1 字节，而汉字通常占 3 字节。该差异会影响 C++ 字符串的长度计算和字符访问。

C++ 标准库提供了两个宏描述环境的编码宽度：

- `MB_LEN_MAX`：实现支持的任何编码中，单个字符最多的字节数，定义在 `<climits>`。
- `MB_CUR_MAX`：当前本地化环境下单个字符最多的字节数，不超过 `MB_LEN_MAX`，定义在 `<cstdlib>`。

竞赛环境中的 `bits/stdc++.h` 会包含这两个宏，通常不需要单独包含相应的头文件。

## 字符的表示方法

字符表示法将字符对应到整数，再通过编码表确定该整数表示的字符。C++ 提供了以下在源码中直接书写整数编号的方式：

- `\123`：八进制，反斜杠后跟三位数字。
- `\x4D`：十六进制，`\x` 后跟十六进制数。
- `\u2620`：Unicode 码点，`\u` 后跟 4 位十六进制。
- `\U0001243F`：Unicode 码点，`\U` 后跟 8 位十六进制。

```cpp
cout << "ABC\n";            // 直接写字符
cout << "\101\102\103\n";   // 八进制转义
cout << "\x41\x42\x43\n";   // 十六进制转义
```

三行都输出 `ABC`：`\101` 和 `\x41` 都等于十进制的 65，对应 `A` 的 ASCII 码。

```cpp
cout << "\u2022 Bullet 1\n";
cout << "\U00002022 Bullet 1\n";
```

两行都输出 `• Bullet 1`。`U+2022` 是项目符号，在 UTF-8 下编码为 3 个字节 `E2 80 A2`。源码中的转义序列在编译后形成字符串中的 3 个字节。

## 多字节字符的表示

在源码中使用字符字面量时，该字符需要属于**基本字符**，即所有可打印的 ASCII 字符（`@`、`$`、`` ` `` 三个字符除外）。按照这一规则，非英语字符应写成码点形式：

```cpp
const char* s = "\u6625\u5929";   // 春天
cout << s << '\n';
```

`U+6625` 是“春”，`U+5929` 是“天”。

目前的源码文件通常使用 UTF-8，编译器也默认按 UTF-8 读取源码，因此中文可以直接写入字面量：

```cpp
const char* s = "春天";
cout << s << '\n';
```

两种写法的结果相同。需要明确指定字面量采用 UTF-8 编码时，可以添加 `u8` 前缀：

```cpp
const char* s = u8"春天";
```

C++20 起，`u8""` 的类型变为 `char8_t[]`，不再与 `char` 通用。相关代码需要区分所使用的 C++ 标准版本。

`\u` 和 `\U` 这两种写法不能用来表示码点小于 `0xA0` 的字符，只有 `$`、`@`、`` ` `` 例外：

```cpp
const char* s = "\u0024\u0040\u0060";   // $@`
cout << s << '\n';
```

C++ 中的 `\u` 属于“通用字符名”（universal character name），在编译的识别阶段代表特定字符，最终按照源码的执行字符集写入字符串。在 UTF-8 环境下，`"\u6625"` 仍会生成 3 个字节的 UTF-8 序列，与直接写“春”没有区别。

### 字节数不等于字符数

字符串包含多字节字符时，“长度”可以指字节数或字符数，两者不再相等。`strlen()`（来自 `<cstring>`）统计的是**字节数**：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    const char* s = "春天";
    cout << strlen(s) << '\n';   // 6
    return 0;
}
```

`s` 包含两个汉字，但 `strlen` 返回 6，因为 UTF-8 中每个汉字占 3 个字节。`string` 的 `size()` 和 `length()` 返回的也是字节数。

`sizeof` 用于字符与字符串时都统计字节数。`sizeof(char)` 恒等于 1，`sizeof` 对这里的字符数组返回包括结尾空字符在内的总字节数：

```cpp
char s[] = "春天";
cout << sizeof(s) << '\n';        // 7：6 个字节 + 结尾的 '\0'
cout << sizeof("春天") << '\n';   // 7，同上

const char* p = "春天";
cout << sizeof(p) << '\n';        // 8（64 位机器上），这是指针的大小，不是字符串长度
```

最后一行体现了数组和指针的差异：`sizeof` 用于数组名时计算整个数组的字节数，用于指针时计算指针本身的字节数。字符串长度应使用 `strlen` 或 `string::size()`，不能使用 `sizeof`。

`<cstring>` 与 `<cctype>` 中的字符串处理函数和字符分类函数按字节处理，多字节字符可能导致 `strchr()`、`strtok()`、`strspn()`、`toupper()`、`tolower()`、`isalpha()` 等函数产生错误结果。例如，`toupper()` 的合法输入仅限于 `unsigned char` 范围内的值；汉字对应的字节不在合法输入范围内，传入这些值会产生未定义行为。

竞赛代码通常按以下方式处理中文：

- **输入中的中文可以按字节处理**。 将整行读入 `string`，需要判断或修改时按字节位置操作。UTF-8 中每个非 ASCII 字节的最高位都是 `1`，汉字的字节不会与其他字符的字节混淆，因此逐字节遍历不会破坏其他字符。
- **字符下标与字节下标不同**。 获取第 2 个汉字时，`s[1]` 得到的是第 2 个**字节**，而不是第 2 个字符。按 UTF-8 的起始字节移动下标时，最高位为 `0` 的字节表示单字节 ASCII 字符，以 `110` 开头的字节是 2 字节字符的首字节，以 `1110` 开头的字节是 3 字节字符的首字节，其他情况以此类推。
- **统计字符数需要先将 UTF-8 解码为码点，再统计码点个数**。

如果程序需要在运行时按本地语言解释字节，可以先用 `setlocale()` 切换本地化环境：

```cpp
setlocale(LC_ALL, "");   // 切到系统当前的本地化设置
```

也可以指定具体环境：

```cpp
setlocale(LC_ALL, "zh_CN.UTF-8");   // 中文 UTF-8
```

`setlocale()` 在 `<clocale>` 中声明。竞赛代码通常不需要调用该函数，因为评测机的输入输出一般是 UTF-8 字节流，按字节读取不依赖评测机是否安装对应的 locale。

## 宽字符

多字节字符串中的字符占用字节数不固定，访问第 n 个字符时需要从字符串开头依次计数。C++ 还提供**宽字符**（wide character）方案：每个字符占固定的字节数，为 2 个或 4 个，按下标访问的时间复杂度为常数。

宽字符类型是 `wchar_t`。它是整数类型的别名，可能有符号，也可能无符号，具体情况由实现决定；其长度为 16 位或 32 位，可以容纳当前系统的任意字符。该类型定义在 `<cwchar>` 中。

宽字符的字面量必须加前缀 `L`，否则会被当成窄字符处理：

```cpp
wchar_t c = L'牛';
```

`L` 位于单引号前时表示宽字符，位于双引号前时表示宽字符串。宽字符串也以空字符结尾，该字符是由一个或多个字节组成的宽空字符。

```cpp
const wchar_t* s = L"春天";
```

宽字符的输出依赖 `wostream` 对 `wchar_t` 及宽字符串的重载。实际代码也可以使用格式化输出函数 `printf`，其中 `%lc` 输出宽字符，`%ls` 输出宽字符串：

```cpp
setlocale(LC_ALL, "");

wchar_t c = L'牛';
printf("%lc\n", c);       // 牛

const wchar_t* s = L"春天";
printf("%ls\n", s);       // 春天
```

`wchar_t` 的宽度与平台相关：Windows 上的 `wchar_t` 是 2 字节，按 UTF-16 存储；Linux 和 macOS 上的是 4 字节，按 UTF-32 存储。同一份代码在不同平台上可能出现不同结果。C++11 增加了两个宽度明确的类型：`char16_t` 对应 UTF-16，`char32_t` 对应 UTF-32，字面量分别是 `u"..."` 和 `U"..."`。C++20 增加了对应 UTF-8 的 `char8_t`，字面量是前文所述的 `u8"..."`。

这些类型很少用于竞赛代码。算法题的输入输出以 ASCII 为主；需要处理中文时，可以按照上一节的方法将其作为“一串字节”处理。

处理宽字符需要使用宽字符专用函数，其中大多数定义在 `<cwchar>` 中。

## 多字节字符处理函数

C++ 标准库提供了一组在多字节表示与宽字符表示之间转换的函数，其原型都定义在 `<cstdlib>` 中。这些函数依赖当前的本地化环境，调用前通常需要执行一次 `setlocale()`。

这些函数很少出现在竞赛代码中。它们用于实现编码之间的转换，具体参数可以在需要时查阅文档。

### mblen()

`mblen()` 返回一个多字节字符占用的字节数。

```cpp
int mblen(const char* mbstr, size_t n);
```

第一个参数是多字节字符串指针，函数只检查它指向的第一个字符；第二个参数是允许检查的最大字节数，通常传入 `MB_CUR_MAX`。

返回值是该字符占用的字节数。如果指向的是空字符（`\0`），返回 `0`；如果这个字节序列不是合法的多字节字符，返回 `-1`。

```cpp
setlocale(LC_ALL, "");

const char* mbs1 = "春天";
cout << mblen(mbs1, MB_CUR_MAX) << '\n';   // 3

const char* mbs2 = "abc";
cout << mblen(mbs2, MB_CUR_MAX) << '\n';   // 1
```

“春”占 3 个字节，“a”占 1 个字节，体现了 UTF-8 的变长编码。计算整个字符串的字符数时，需要使用该函数依次读取并统计每个字符。

### wctomb()

`wctomb()`（wide character to multibyte）将单个宽字符转换为多字节表示。

```cpp
int wctomb(char* s, wchar_t wc);
```

第一个参数是存放结果的多字节数组，第二个参数是待转换的宽字符。返回值是转换后占用的字节数；无法转换时返回 `-1`。如果第一个参数是空指针，函数只返回“当前环境下一个宽字符最多需要多少字节”，不执行转换。

```cpp
setlocale(LC_ALL, "");

wchar_t wc = L'牛';
char mbStr[10] = "";

int nBytes = wctomb(mbStr, wc);

cout << mbStr << '\n';    // 牛
cout << nBytes << '\n';   // 3
```

### mbtowc()

`mbtowc()` 执行相反的转换，将多字节字符转换为宽字符。

```cpp
int mbtowc(wchar_t* wchar, const char* mbchar, size_t count);
```

三个参数分别是目标宽字符指针、待转换的多字节字符指针和允许读取的最大字节数。返回值是已读取的多字节字符所占的字节数，转换失败时返回 `-1`。

```cpp
setlocale(LC_ALL, "");

const char* mbchar = "牛";
wchar_t wc;

int nBytes = mbtowc(&wc, mbchar, 3);

cout << nBytes << '\n';    // 3
printf("%lc\n", wc);       // 牛
```

### wcstombs()

`wcstombs()` 将整个宽字符串转换为多字节字符串。

```cpp
size_t wcstombs(char* mbstr, const wchar_t* wcstr, size_t count);
```

三个参数是目标多字节缓冲区、待转换的宽字符串以及缓冲区可容纳的最大字节数。转换成功时返回写入的字节数（**不含**结尾的 `\0`），失败时返回 `-1`。第一个参数为空指针时，函数只返回转换所需的字节数，可以据此确定缓冲区大小。

```cpp
setlocale(LC_ALL, "");

char mbs[20];
const wchar_t* wcs = L"春天";

size_t nBytes = wcstombs(mbs, wcs, 20);

cout << mbs << '\n';       // 春天
cout << nBytes << '\n';    // 6
```

两个汉字转成 UTF-8 是 6 个字节，和 `strlen("春天")` 的结果一致。

### mbstowcs()

`mbstowcs()` 执行相反的转换，将多字节字符串转换为宽字符串。

```cpp
size_t mbstowcs(wchar_t* wcstr, const char* mbstr, size_t count);
```

三个参数是目标宽字符串、待转换的多字节字符串以及最多转换的字符数。转换成功时返回转换后的字符数，失败时返回 `-1`。如果返回值等于 `count`，目标宽字符串没有以空字符结尾，因为缓冲区已写满并发生截断。

```cpp
setlocale(LC_ALL, "");

const char* mbs = "天气不错";
wchar_t wcs[20];

size_t nChars = mbstowcs(wcs, mbs, 20);

printf("%ls\n", wcs);      // 天气不错
cout << nChars << '\n';    // 4
```

“天气不错”包含 4 个字符，因此返回 4。这里统计的是**字符**而不是字节，与 `strlen` 返回的 12 不同。这组 API 中只有这一对函数可以正确统计字符数，但它们依赖本地化环境，并且需要额外复制一份内存，因此竞赛代码通常按字节处理。

第一个参数为空指针时，`mbstowcs()` 返回目标宽字符串会包含的字符数。
