# C++ 简介

## 历史

C++ 是从 C 语言长出来的一门语言。

1979 年，贝尔实验室的比雅尼·斯特劳斯特鲁普（Bjarne Stroustrup）开始用 C 语言做系统研究，他觉得 C 的执行效率很好，但表达复杂结构时太笨拙。于是他在 C 语言之上加入类、继承、类型检查等特性，做出一门能“带上类（class）的 C”。1983 年，这门语言正式定名为 C++——`++` 是自增运算符，表示 C 的“升级版”。

此后 C++ 一路扩张，从最初的“更好的 C”变成支持多种编程范式的通用语言。1998 年，国际标准化组织（ISO）发布了第一个标准，此后大致每三年修订一次，标准编号逐年累加（C++11、C++14、C++17……）。

今天，C++ 既用在操作系统、数据库、游戏引擎这类追求性能的底层软件里，也是算法竞赛的事实标准语言之一。

## C++ 的特点

C++ 能同时吸引系统开发者和算法竞赛选手，靠的是几条互相支撑的特性。

**兼容 C。** 绝大多数合法的 C 代码，C++ 编译器都能直接编译。这意味着一份 C 程序往往改几行就能当 C++ 用，学 C 的知识不会白费。

**运行效率高。** C++ 的设计原则之一叫“零开销抽象”：不用的特性不用付出代价，用了的抽象也尽量编译成和手写底层代码一样的机器指令。它的执行速度和 C 基本在同一档。

**抽象能力强。** 类、模板、运算符重载让程序员能用接近自然语言的方式描述复杂结构，而不必手工管理每一个字节。

**自带标准模板库（STL）。** 这是竞赛里最关键的一点。动态数组、字符串、哈希表、排序、二分查找这些原本要自己写几十行的东西，STL 都有现成实现，调用几行就完成，既快又不容易出错。

正因为如此，算法竞赛里 C++ 几乎是默认语言：同一道题，用它实现的数据结构往往比 C 短一半、错得更少。

## C++ 的版本

C++ 的标准不止一个版本，版本之间差异不小，写代码前要先确认用的哪一版。

| 版本 | 年份 | 主要变化 |
| --- | --- | --- |
| C++98 | 1998 | 第一个 ISO 标准，奠定语言基础 |
| C++03 | 2003 | 对 C++98 的小幅修订 |
| C++11 | 2011 | 重大更新：`auto`、范围 for、lambda、智能指针 |
| C++14 | 2014 | 完善 C++11，放宽部分语法限制 |
| C++17 | 2017 | 结构化绑定、`if` 初始化语句、更多库 |
| C++20 | 2020 | 概念（concepts）、协程、范围库 |
| C++23 | 2023 | 继续扩充，紧接 C++20 的修补 |

竞赛平台的编译器通常较新，**C++17 是目前兼容性最好、特性也够用的选择**；平台若支持，直接用 C++20 也没有问题。本书的示例默认按 C++17 讲解。

## C++ 的编译

C++ 和 C 一样是编译型语言：源码是纯文本，不能直接运行，必须先由编译器翻译成二进制可执行文件。

常用的编译器是 GCC 套件里的 `g++`。把源码存成 `hello.cpp`，在命令行执行：

```bash
g++ hello.cpp
```

默认生成的可执行文件叫 `a.out`（Windows 上是 `a.exe`）。运行它：

```bash
./a.out
```

`g++` 的 `-o` 参数（output）可以指定产物名：

```bash
g++ -o hello hello.cpp
./hello
```

`-std=` 参数指定语言标准，`-O2` 打开常用的性能优化——竞赛代码几乎都会带上 `-O2`：

```bash
g++ -std=c++17 -O2 -o hello hello.cpp
```

这条命令可以记成一句口头禅：**用 C++17、开 O2、产物叫 hello**。后面的章节默认按这个方式编译。

## Hello World 示例

C++ 源码文件以 `.cpp` 结尾（也有 `.cc`、`.cxx`，竞赛里统一用 `.cpp` 就行）。下面是一个完整的 C++ 程序。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
```

和入门章节里那版相比，这里换了两处写法，正是竞赛代码的惯用开头：

- `#include <bits/stdc++.h>` 是 GCC 提供的“万能头文件”，一条指令就把标准库几乎全部内容包含进来，省去逐个 `#include`。代价是编译稍慢一点，但竞赛里可以忽略。
- `using namespace std;` 把标准库的名字一次性引入全局命名空间，这样可以直接写 `cout` 而不用写 `std::cout`。工程代码里一般不这么干（容易撞名），竞赛里则图省事，几乎人人这么写。

`main()` 是程序的入口，`cout << "Hello, world!" << endl;` 把字符串送到屏幕并换行，`return 0;` 表示程序正常结束。

关于 `bits/stdc++.h`、`using namespace std` 和 `cout` 的细节，会在《基本语法》和《输入输出》两章里展开。这里只需要先记住一件事：**竞赛里，一段完整的 C++ 程序长这样开头。**
