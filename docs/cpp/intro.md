# C++ 简介

## 历史

C++ 在 C 语言的基础上扩展而成。C 是一门更早出现的编程语言，语法贴近计算机底层，执行效率高，至今仍用于操作系统这类系统软件。

1979 年，贝尔实验室的比雅尼·斯特劳斯特鲁普（Bjarne Stroustrup）开始用 C 语言进行系统研究。C 语言执行效率高，但缺少组织大型程序的语法机制，例如把数据和操作封装在一起的结构。他在 C 语言之上加入类、继承、类型检查等特性，形成一门“带类（class）的 C”。1983 年，该语言正式定名为 C++；`++` 是自增运算符，表示 C 的后续版本。

此后 C++ 增加了更多语言特性，从一门带类的语言发展为支持多种编程范式的通用语言。1998 年，国际标准化组织（ISO）发布了第一个标准，此后大致每三年修订一次，标准编号逐年累加（C++11、C++14、C++17……）。

今天，C++ 既用在操作系统、数据库、游戏引擎这类追求性能的底层软件里，也是算法竞赛的事实标准语言之一。

## C++ 的特点

C++ 适用于系统开发与算法竞赛，取决于以下几项特性。

**运行效率高。** C++ 的设计原则之一是“零开销抽象”：未使用的特性不产生额外开销，已使用的抽象会被编译为与手写底层代码等价的机器指令。在常用编程语言中，C++ 的执行速度属于最快的那一档。

**抽象能力强。** 类、模板与运算符重载提供了描述复杂结构的语法机制，减少了需要手工编写的底层管理代码。

**自带标准模板库（STL）。** STL 提供动态数组、字符串、哈希表、排序、二分查找等数据结构与算法的现成实现，这些结构若手工实现需要编写较多代码。

算法竞赛普遍使用 C++：标准库提供了现成的数据结构与算法，同一道题用 C++ 实现的代码量通常少于自行实现这些结构的写法，出错也更少。

## C++ 的版本

C++ 有多个标准版本，各版本之间存在语法与库差异，编写代码前需确定所用的版本。

| 版本 | 年份 | 主要变化 |
| --- | --- | --- |
| C++98 | 1998 | 第一个 ISO 标准，奠定语言基础 |
| C++03 | 2003 | 对 C++98 的小幅修订 |
| C++11 | 2011 | 重大更新：`auto`、范围 for、lambda、智能指针 |
| C++14 | 2014 | 完善 C++11，放宽部分语法限制 |
| C++17 | 2017 | 结构化绑定、`if` 初始化语句、更多库 |
| C++20 | 2020 | 概念（concepts）、协程、范围库 |
| C++23 | 2023 | 继续扩充，紧接 C++20 的修补 |

竞赛平台的编译器通常较新，**C++17 是目前兼容性最好、特性也够用的选择**；平台若支持，直接用 C++20 也没有问题。本书的示例默认按 C++17 讲解。

## C++ 的编译

C++ 是编译型语言：源码是纯文本，不能直接运行，必须先由编译器翻译成二进制可执行文件。

常用的编译器是 GCC 套件里的 `g++`。把源码存成 `hello.cpp`，在命令行执行：

```bash
g++ hello.cpp
```

默认生成的可执行文件叫 `a.out`（Windows 上是 `a.exe`）。运行它：

```bash
./a.out
```

`g++` 的 `-o` 参数（output）可以指定产物名：

```bash
g++ -o hello hello.cpp
./hello
```

`-std=` 参数指定语言标准，`-O2` 打开常用的性能优化——竞赛代码几乎都会带上 `-O2`：

```bash
g++ -std=c++17 -O2 -o hello hello.cpp
```

后续章节默认使用这一组选项：C++17 标准、`-O2` 优化、产物名为 `hello`。

## Hello World 示例

C++ 源码文件以 `.cpp` 结尾，也可使用 `.cc` 或 `.cxx`，竞赛代码统一使用 `.cpp`。下面是一个完整的 C++ 程序。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, world!" << endl;
    return 0;
}
```

与入门章节的版本相比，此处有两处写法不同，均为竞赛代码的常见开头：

- `#include <bits/stdc++.h>` 是 GCC 提供的一次性包含全部标准库头文件的头文件，无需逐个书写 `#include`。缺点是编译耗时略长，竞赛场景下这一开销可忽略。
- `using namespace std;` 把标准库的名字一次性引入全局命名空间，可以直接写 `cout` 而不必写 `std::cout`。工程代码通常省略这一行以避免命名冲突，竞赛代码普遍保留，以减少重复的限定符。

`main()` 是程序的入口，`cout << "Hello, world!" << endl;` 把字符串送到屏幕并换行，`return 0;` 表示程序正常结束。

《基本语法》与《输入输出》两章会展开 `bits/stdc++.h`、`using namespace std` 和 `cout` 的细节。竞赛中的 C++ 程序通常采用上述开头。
