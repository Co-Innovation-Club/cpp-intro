# 指针

指针（pointer）保存的是一个内存地址。它是 C++ 中直接操作内存的主要方式，也是常见的错误来源之一。

竞赛代码中直接使用裸指针（raw pointer）的场景不多：需要修改实参的形参可以写成引用（`int&`）而非 `int*`；长度不定的序列可以用 `vector` 而非 `new int[n]`；字符串可以用 `string` 而非 `char*`。这些类型在内部封装了地址运算，使用时不涉及显式的地址操作。

数组名在多数场合会退化成指针，函数传递大型对象、迭代器、`sort` 的比较函数、`new` 与内存布局的实现都依赖指针。本章要求能够阅读并解释涉及指针的代码，而非把指针作为主要工具使用。

## 简介

指针是一个值，它表示一个内存地址。

`*` 表示指针，通常跟在类型关键字后面，说明指针指向的是什么类型的值。`char*` 是指向字符的指针，`float*` 是指向 `float` 的指针。

```cpp
int* intPtr;
```

上面声明了变量 `intPtr`，它是一个指针，指向的内存地址里存放一个整数。

星号 `*` 可以放在变量名与类型关键字之间的任何位置，下面几种写法都合法：

```cpp
int   *intPtr;
int * intPtr;
int*  intPtr;
```

本书把星号紧跟在类型关键字后面写（`int* intPtr;`），这样能看出“指针变量也是普通变量，只不过它的值是地址”。

同一行声明两个指针变量时，每个变量名前面都要有星号。

```cpp
// 正确
int *foo, *bar;

// 错误：foo 是指针，bar 是普通 int
int* foo, bar;
```

指针指向的还可以是另一个指针，这时要用两个星号 `**`。

```cpp
int** foo;
```

`foo` 是一个指针，它指向的还是一个指针，第二个指针才指向一个 `int`。这种写法在竞赛里主要出现在二维数组传参和某些动态结构里，阅读时从最内层开始向外逐层解析。

顺带一个和内存有关的事实：**在 64 位平台上，任何指针都占 8 个字节**，和它指向的类型无关——`char*` 和 `double*` 都是 8 字节，因为它们存的都是 64 位地址。

## * 运算符

`*` 除了表示指针类型，还是一个运算符，用来取出指针所指向地址里存的值，这叫做**解引用（dereference）**。

```cpp
void increment(int* p) {
    *p = *p + 1;
}
```

`increment()` 的参数是一个整数指针 `p`。函数体里 `*p` 表示 `p` 指向的那个值，对 `*p` 赋值，就是改掉这个地址里存的内容。

这个函数没有返回值，因为它传入的是地址，函数内对地址里内容的修改会留在函数外部。**要把修改带出函数，C++ 中通常使用引用（reference）而不是指针**，见《函数》一章。

传值需要对大型变量进行复制，消耗时间和空间；传地址（或引用）不产生副本。

## & 运算符

`&` 运算符取出一个变量所在的内存地址，叫做**取址（address-of）**。

```cpp
#include <bits/stdc++.h>
using namespace std;

void increment(int* p) {
    *p = *p + 1;
}

int main() {
    int x = 1;
    cout << &x << '\n';   // 输出 x 的地址，形如 0x16f...（每次运行可能不同）
    increment(&x);
    cout << x << '\n';    // 2
    return 0;
}
```

（这两行开头是竞赛代码的固定写法：`bits/stdc++.h` 一次引入标准库，`using namespace std;` 免去逐个写 `std::`。代价是编译稍慢、命名空间被污染，工程代码不这么写，竞赛里默认如此。详见《C++ 简介》。）

`&x` 就是变量 `x` 的值所在的内存地址。用 `cout` 直接输出一个指针，打印的就是这个地址；要格式化输出，`printf` 里对应的占位符是 `%p`。

调用 `increment(&x)` 之后，`x` 的值变成 2，原因就是传进去的是 `x` 的地址 `&x`。

`&` 和 `*` 互为逆运算：对变量取址再解引用，拿回来的还是它自己。

```cpp
int i = 5;
cout << (i == *(&i)) << '\n';   // 1，即 true
```

## 指针变量的初始化

声明指针变量后，编译器会为指针本身分配内存，但**这块内存里的值是随机的**。指针指向的位置不确定，此时不能读写它指向的地址。

```cpp
int* p;
*p = 1;   // 错误：往一个随机地址里写数据
```

这行代码可能导致程序立即崩溃，也可能覆盖其他数据，在运行一段时间后才出错；后者更难定位。这类指向无效位置的指针叫**野指针（wild pointer）**。

指针初始化是指：指针声明后先指向一块已经分配好的地址，再进行读写。

```cpp
int* p;
int i;

p = &i;     // 让 p 指向 i
*p = 13;    // 现在可以安全地写入
```

这里 `i` 由编译器分配了地址，`p = &i;` 之后 `p` 指向 `i`，于是 `*p = 13;` 等价于 `i = 13;`。

没有可指向的对象时，把指针设为**空指针**，用关键字 `nullptr` 表示：

```cpp
int* p = nullptr;   // C++ 写法，推荐
int* q = NULL;      // 也能编译，但 NULL 本质上常被定义成 0，类型信息不明确
```

`nullptr` 是 C++11 引入的关键字，类型是 `std::nullptr_t`，专门表示“不指向任何对象”。宏 `NULL` 是等价的旧写法，在旧代码里仍然常见。它比 `NULL` 明确：`NULL` 在大多数实现里就是整数常量 `0`，碰到重载时可能被当成 `int` 传进去而出错，`nullptr` 不会。空指针不能解引用，写 `*p` 会出错；但判断“指针是否有效”时，`p == nullptr`（或直接写 `if (!p)`）是合法且常用的。

指针在声明时初始化为 `nullptr`，可以避免解引用未初始化指针引发的错误。

## 指针的运算

指针的值是一个表示地址的整数，其运算规则与指向的类型绑定，不能按普通整数的方式运算。

**（1）指针与整数的加减。**

指针加减一个整数，表示指针的移动。移动的单位不是 1 个字节，而是**一个元素**。

```cpp
short* j;
j = (short*)0x1234;
j = j + 1;    // 0x1236
```

`j` 指向地址 `0x1234`。`0x1234` 本身是整数，和 `short*` 类型不匹配，所以用 `(short*)` 强制转换。`j + 1` 的结果不是 `0x1235` 而是 `0x1236`：一个 `short` 占 2 个字节，移动一个单位就是移动 2 个字节。同理 `j - 1` 得到 `0x1232`。

**移动的字节数 = 元素个数 × 该类型的字节宽度**，这是指针运算的基本规则。`int*` 加 1 走 4 字节，`double*` 加 1 走 8 字节。

**（2）指针与指针相加是非法的。**

两个指针相加没有意义，编译器会报错。

```cpp
unsigned short* j;
unsigned short* k;
// j + k;   // 错误
```

**（3）指针与指针相减，得到两者之间的距离。**

类型相同的两个指针可以相减，结果是它们相隔多少个元素（不是字节数）。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[5] = {11, 22, 33, 44, 55};
    int* p = &a[1];
    int* q = &a[4];

    cout << (q - p) << '\n';   // 3
    cout << (p - q) << '\n';   // -3
    return 0;
}
```

高位地址减低位地址得正值，反过来得负值。这个结果的类型是 `ptrdiff_t`，一种带符号的整数类型别名，定义在 `<cstddef>` 里（被 `bits/stdc++.h` 一并包含）。竞赛代码通常把该结果与 `int` 比较。`ptrdiff_t` 是有符号类型，与 `size_t` 混用时会因符号性不同产生隐式转换问题。

**（4）指针之间的比较。**

指针可以比较大小，比较的是地址的高低，结果是 `bool`。

```cpp
int* p = &a[1];
int* q = &a[4];
cout << (p < q) << '\n';    // 1，即 true
```

比较只在**同一个数组（或同一块连续内存）**里才有明确意义。拿两个不相干对象的地址比大小属于未定义行为。

### 指针与数组

指针运算最实际的用途是遍历数组。数组名在大多数表达式里会**退化（decay）**成指向首元素的指针，所以下面两行是等价的：

```cpp
int a[5] = {11, 22, 33, 44, 55};

int* p = &a[0];
int* p = a;        // 与上一行等价
```

由数组名退化可得竞赛里常用的一条恒等式：

```cpp
a[i] == *(a + i)
```

`a[i]` 是 `*(a + i)` 的简写：`a + i` 先算出第 `i` 个元素的地址，再用 `*` 取出值。用指针遍历数组就是把这个式子写开：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a[5] = {11, 22, 33, 44, 55};

    for (int i = 0; i < 5; i++)
        cout << *(a + i) << ' ';   // 11 22 33 44 55
    cout << '\n';

    // 或者用一个会移动的指针
    for (int* p = a; p != a + 5; p++)
        cout << *p << ' ';
    cout << '\n';
    return 0;
}
```

数组名本身不能移动：数组名的地址是绑定的，`a++` 会报错，必须先把 `a` 赋给一个指针变量，再让指针自增。这也是“数组名相当于常量指针”的含义。

竞赛代码中遍历数组通常使用范围 `for`（写 `for (int x : a)`）或 `vector` 的迭代器。阅读他人的代码、理解 `lower_bound` 返回的迭代器、看懂二维数组传参，都需要这一层基于地址的视角。
