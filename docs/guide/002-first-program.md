# 跑通「Hello World」

完成环境搭建后，编写并运行第一个可执行的程序。

## 写代码

启动软件时会新建一个空白文件，也可以按<kbd>Ctrl</kbd>+<kbd>N</kbd>新建 C/C++ 文件。

在编辑区输入以下代码：

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, world!";
    return 0;
}
```

![写完代码的编辑区](https://km.r379.com/azspace/i/2026/09/27/51z_1.webp)

注意标签页文件名后面的 `[*]`，星号表示该文件尚未保存。

## 保存

点工具栏上的保存按钮，或按<kbd>Ctrl</kbd>+<kbd>S</kbd>，弹出另存为窗口。

![另存为窗口，保存类型选择「C++语言文件」](https://km.r379.com/azspace/i/2026/09/27/51i.webp)

**保存类型**选 `C++语言文件 (*.cpp,*.cc,*.cxx)`，文件名会自动带上后缀。

::: warning 扩展名决定语言
`.cpp` 按 C++ 编译，`.c` 按 C 编译。C++ 源码请统一保存为 `.cpp`。
:::

## 编译并运行

菜单栏的「运行」里集中了所有与运行相关的命令：

![展开的「运行」菜单，列出编译 F9、运行 F11、全部重新编译 F12、调试 F5 等命令](https://km.r379.com/azspace/i/2026/09/27/6v3z.webp)

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| 编译 | <kbd>F9</kbd> | 只生成可执行文件，不运行 |
| 运行 | <kbd>F11</kbd> | 编译并立即运行 |
| 全部重新编译 | <kbd>F12</kbd> | 从头重新编译所有文件 |
| 编译器选项… | — | 设置 C++ 标准、警告级别等 |

修改代码后按 <kbd>F11</kbd> 编译并运行。菜单里的「生成汇编」「生成 GIMPLE 表示」「预处理」属于进阶用法。

## 看运行结果

![控制台窗口输出Hello, world!，并显示进程退出信息](https://km.r379.com/azspace/i/2026/09/27/zbg.webp)

控制台输出 `Hello, world!`，程序结束后显示：

```
进程退出，总耗时 0.1193 s.  返回值: 0; CPU 时间: 0.0000 ms; 内存: 912 KB.
按任意键退出...
```

控制台还会显示**返回值**：`0` 表示程序正常结束，非 0 值表示程序异常退出。

按任意键关闭这个窗口。
