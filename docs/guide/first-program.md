# 跑通「Hello World」

装好之后，写一个能跑起来的程序。

## 写代码

启动时软件已经开好一个空白文件。也可以按<kbd>Ctrl</kbd>+<kbd>N</kbd>新建一个C/C++文件。

把下面几行敲进去：

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "Hello, world!";
    return 0;
}
```

![写完代码的编辑区](https://km.r379.com/azspace/i/2026/09/27/51z_1.webp)

注意标签页文件名后面的`[*]`——星号表示这个文件还没保存。

## 保存

点工具栏上的保存按钮，或按<kbd>Ctrl</kbd>+<kbd>S</kbd>，弹出另存为窗口。

![另存为窗口，保存类型选择「C++语言文件」](https://km.r379.com/azspace/i/2026/09/27/51i.webp)

**保存类型**选`C++语言文件 (*.cpp,*.cc,*.cxx)`，文件名会自动带上后缀。

::: warning 扩展名决定语言
`.cpp`按C++编译，`.c`按C编译。写C++请一律存`.cpp`。
:::

## 编译并运行

菜单栏的「运行」里集中了所有与运行相关的命令：

![展开的「运行」菜单，列出编译F9、运行F11、全部重新编译F12、调试F5等命令](https://km.r379.com/azspace/i/2026/09/27/6v3z.webp)

| 命令 | 快捷键 | 说明 |
| --- | --- | --- |
| 编译 | <kbd>F9</kbd> | 只生成可执行文件，不运行 |
| 运行 | <kbd>F11</kbd> | 编译并运行，一步到位 |
| 全部重新编译 | <kbd>F12</kbd> | 从头重新编译所有文件 |
| 编译器选项… | — | 设置C++标准、警告级别等 |

**改完代码按<kbd>F11</kbd>。** 菜单里的「生成汇编」「生成GIMPLE表示」「预处理」属于进阶用法。

## 看运行结果

![控制台窗口输出Hello, world!，并显示进程退出信息](https://km.r379.com/azspace/i/2026/09/27/zbg.webp)

控制台打印出`Hello, world!`，程序结束后显示：

```
进程退出，总耗时 0.1193 s.  返回值: 0; CPU 时间: 0.0000 ms; 内存: 912 KB.
按任意键退出...
```

看**返回值**：`0`表示程序正常结束。如果是别的数字，说明程序中途异常退出了。

按任意键关闭这个窗口。

## 中文输出乱码

控制台里中文显示为乱码时，先看状态栏的文件编码（正常是UTF-8），再检查「编译器选项…」里与字符集相关的设置。
