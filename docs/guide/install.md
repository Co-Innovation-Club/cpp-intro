# 搭建开发环境

小熊猫C++是Windows上的C/C++集成开发环境，安装包自带编译器，装完即可编译运行。

## 一、运行安装包

下载安装包后双击运行。第一个弹出的是语言选择窗口。

![安装向导的语言选择窗口，已选中「中文(简体)」](https://km.r379.com/azspace/i/2026/09/27/51z.webp)

选中「中文(简体)」，点「OK」。之后的向导就是中文界面了。

## 二、接受许可协议

![许可协议窗口，底部按钮为「我接受(I)」与「取消(C)」](https://km.r379.com/azspace/i/2026/09/27/1c4hz.webp)

向导会先显示许可证条款，点「我接受(I)」继续安装。

## 三、选择用户

![选择用户窗口，两个选项分别是「为本机所有用户安装」与「只为我安装」](https://km.r379.com/azspace/i/2026/09/27/1c8gz.webp)

选择安装范围：只给自己用选「只为我安装(M)」，本机各账号共用选「为本机所有用户安装(A)」。点「下一步(N)」。

## 四、选择组件

![选择组件窗口，列出要安装的组件与占用空间](https://km.r379.com/azspace/i/2026/09/27/6w10.webp)

向导列出要安装的组件，其中包含自带的MinGW-w64 x64 GCC 11.5.0编译器。保持默认勾选，点「下一步(N)」。

## 五、选择安装位置

![选择安装位置窗口，安装目录默认为AppData下的RedPanda-Cpp](https://km.r379.com/azspace/i/2026/09/27/z9q.webp)

向导给出的默认安装目录是：

```
C:\Users\<用户名>\AppData\Local\Programs\RedPanda-Cpp
```

**默认路径可直接使用**，点「安装(I)」。窗口里还会显示所需空间与当前可用空间，装之前扫一眼，确认磁盘够用。

## 六、开始安装

![正在安装窗口，逐个解压编译器与编辑器的文件](https://km.r379.com/azspace/i/2026/09/27/6w69.webp)

点「安装(I)」后向导开始复制文件，逐个解压编译器与编辑器的文件。这一步只需等待。

## 七、安装结束

![安装结束窗口，默认勾选「运行 小熊猫C++ 3.4 (x64)(R)」](https://km.r379.com/azspace/i/2026/09/27/zfg.webp)

进度条走完即安装完成。默认勾选的「运行 小熊猫C++ 3.4 (x64)(R)」会让软件在点「完成(F)」后直接启动。

## 八、首次启动：选择主题

装完启动软件，第一件事是选主题。

![首次启动的主题选择窗口，左侧深色主题、右侧浅色主题，底部可选默认语言C/C++](https://km.r379.com/azspace/i/2026/09/27/zbo.webp)

- 左边是深色主题，右边是浅色主题，点一下就能切换预览
- 底部「默认语言」选 **C / C++**
- 选好后点「确定」

主题以后随时能改。

## 九、认识主界面

![主界面，中央是空白编辑区，底部是编译器输出面板](https://km.r379.com/azspace/i/2026/09/27/zdz.webp)

启动后软件会自动开好一个空白文件，标题栏显示`untitled1.cpp`。界面分成几块：

| 区域 | 内容 |
| --- | --- |
| 菜单栏 | 文件、编辑、选择、视图、查找、代码、重构、运行、工具、窗口、帮助 |
| 工具栏 | 新建、打开、保存、撤销重做、编译、运行、调试等按钮 |
| 左侧面板 | 文件、项目、监视、结构、试题集 |
| 中间编辑区 | 写代码的地方，顶部标签页切换文件 |
| 底部面板 | 编译器、工具输出、调试、查找、TODO、书签、试题 |
| 右上角 | 当前编译器：MinGW-w64 GCC 11.5.0 64-bit Debug |
| 状态栏 | 光标行列、文件编码、插入/改写状态 |

面板可以拖动、隐藏。左侧和底部的面板如果关掉了，在「视图」菜单里能重新打开。
